### 2.2 텍스트 — **대비비 AA(4.5:1) 통과값으로 재정의**

기존 PRD-04의 보조 텍스트 `#8B95A1`은 흰 배경에서 **약 2.9:1로 AA 미달**이었다.
아래로 교체하고, `#8B95A1`은 비활성·플레이스홀더 전용으로 강등한다.

| 토큰 | 값 | 대비비(on `#FFFFFF`) | 용도 |
|---|---|---|---|
| `--text` | `#191F28` | 15.8:1 | 제목, 본문 |
| `--text-secondary` | `#4E5968` | 7.6:1 | 요약문, 설명 |
| `--text-tertiary` | `#6B7684` | 4.9:1 | 메타(저자·날짜·매체명) |
| `--text-disabled` | `#8B95A1` | 2.9:1 | **비활성·placeholder 전용.** 정보 전달에 쓰지 말 것 |
| `--text-inverse` | `#FFFFFF` | — | 컬러 면 위 텍스트 |

### 2.3 포인트 컬러 — 용처 재정의 (C-8 후속, §2.2 모순 해소)

PRD-04 §4.1에서 "원문 이동 버튼"이 사라져 포인트 컬러의 원래 용처 하나가 없어졌고,
대신 배지·토글·하이라이트가 새로 생겼다. 아래로 다시 정의한다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--point` | `#3182F6` | 기본 포인트 — 링크, 활성 토글, 포커스 링, 파비콘 |
| `--point-weak` | `#E8F3FF` | 포인트의 옅은 면 (뉴스 배지 배경) |
| `--paper` | `#15C47E` | 논문 식별색 — 논문 배지, 논문 카드 좌측 바 |
| `--paper-weak` | `#E5F8F0` | 논문 배지 배경 |
| `--warn` | `#FF9500` | "초록만" 상태 배지 |
| `--warn-weak` | `#FFF4E5` | 위 배경 |
| `--danger` | `#F04452` | 번역 실패, 오류 화면 |
| `--danger-weak` | `#FEECEE` | 위 배경 |
| `--highlight` | `#FFF3C4` | 검색어 하이라이트 배경 (텍스트는 `--text` 유지) |

**"큰 색면 금지"(NFR-1)와의 양립** — 포인트 컬러는 **배지·1px 보더·좌측 4px 바·
텍스트·아이콘**에만 쓴다. 버튼 이상 크기의 채워진 면은 `--point` 하나만 허용하며
페이지당 1개를 넘지 않는다(예: 검색 실행 버튼).

**카테고리 태그(국제/국내)는 색으로 구분하지 않는다.** 둘 다 `--bg-subtle` 면에
`--text-secondary` 텍스트를 쓴다. 구분은 글자 그 자체다 — NFR-5의 "색상 외 구분"을
가장 확실하게 만족시키고, 색 사용도 아낀다.

### 2.4 다크 모드 — 1차 미지원 (확정)

1차 범위에서 다크 모드를 지원하지 않는다. 다만 위 토큰을 **전부 CSS 변수로 선언**해
나중에 `:root[data-theme="dark"]` 블록만 추가하면 되도록 구조를 남긴다.
색상값을 컴포넌트에 직접 쓰지 말 것.

## 3. 타이포그래피

### 3.1 서체 — 전면 산세리프 확정 (C-8 해소)

**Pretendard 단일 체계. 세리프를 쓰지 않는다.**
매거진 톤의 세리프 혼용은 철회한다 — Toss 톤은 단일 산세리프 체계이며,
두 지시가 충돌할 때 나중 지시(Toss)를 따른다.

로딩은 **로컬 서브셋 배치**(`frontend/public/fonts/`). CDN을 쓰지 않는다 —
온프레미스 배포(`architecture.md` §1)에서 외부 CDN 의존은 단일 실패점이 된다.
서브셋: KS X 1001 한글 2350자 + Latin + 숫자/기호, woff2, weight 400/500/600/700/800.

## 4. 스페이싱 · 레이아웃

### 4.1 스페이싱 (4pt 스케일)

`--s1:4` `--s2:8` `--s3:12` `--s4:16` `--s5:20` `--s6:24` `--s8:32` `--s10:40` `--s12:48` `--s16:64` `--s20:80` (px)

### 4.2 브레이크포인트

| 이름 | 범위 | 컨테이너 최대폭 | 좌우 거터 | 카드 열 수 |
|---|---|---|---|---|
| Mobile | `< 768px` | 100% | 16px | 1 |
| Tablet | `768 ~ 1023px` | 100% | 24px | 2 |
| Desktop | `≥ 1024px` | 1200px | 32px | 3 |

그리드 간격: 카드 사이 `--s6`(24px), 섹션 사이 `--s16`(64px), 모바일은 각각 16/40px.

### 4.3 그리드 방식 — 균일 CSS Grid 확정

**뉴스·논문 모두 높이가 균일한 CSS Grid를 쓴다. Masonry를 쓰지 않는다.**
Toss 톤의 핵심은 정렬감이고, Masonry는 열마다 하단이 어긋나 산만해진다.
구현도 단순하다(`grid-template-columns: repeat(auto-fill, minmax(…, 1fr))`).

카드 높이는 요약문 줄수 클램프(뉴스 3줄, 논문 3줄)로 맞춘다.

## 6. 3D Hero 강도 기준 (Toss 톤과의 양립)

Toss 톤의 절제와 인터랙티브 3D는 그냥 두면 충돌한다. 아래를 상한으로 고정한다.

| 항목 | 기준 |
|---|---|
| 모티프 | **떠 있는 데이터 노드(네트워크 토폴로지)** 단일 채택 (PRD-04 FR-4의 3개 후보 중) |
| 색 | 노드·엣지는 무채색 `--border-strong`(`#D1D6DB`). 전체 노드의 **15% 이하**만 `--point` |
| 밀도 | 노드 40개 이하, 엣지 80개 이하 |
| 배경 | 투명 — 페이지의 `--bg`(흰색)가 그대로 비친다. 그라디언트·어두운 배경 금지 |
| 마우스 반응 | 카메라 회전 진폭 **±4°**, `lerp` 계수 `0.05` (급격한 추종 금지) |
| 자동 회전 | `0.05 rad/s` 이하. 정지해 있어도 어색하지 않을 것 |
| 카피 가독성 | 3D는 카피 뒤에 있다. 카피 영역 뒤 노드는 opacity 0.35로 낮춘다 |
| DPR | `Math.min(devicePixelRatio, 1.5)` 상한 |
| 모바일 (`< 768px`) | **3D를 렌더링하지 않는다.** 정적 SVG 폴백 (NFR-4) |
| 모션 저감 | `prefers-reduced-motion: reduce`면 자동 회전·마우스 추종 정지, 정지 프레임만 |

**왜 노드 토폴로지인가** — 자물쇠는 상징이 진부하고 매트릭스 스트림은 채도·모션이
Toss 톤과 정면 충돌한다. 점과 선은 무채색으로도 성립해 흰 배경 위에서 가장 조용하다.

## 7. 상태 화면 (PRD-06 FR-5, PRD-04 FR-25·FR-26)

| 상태 | 처리 |
|---|---|
| 로딩 | **스켈레톤.** 카드 형태를 `--bg-subtle` 면으로 그리고 `1.5s` 펄스. 스피너 금지 |
| 결과 없음 (검색) | 아이콘 없이 텍스트만 — 질의어, **검색 범위 안내**(PRD-05 §4.2), 대체 제안 |
| 결과 없음 (구독 피드) | "기본 수집 범위(보안/해킹/사이버/AI) 밖일 수 있습니다" (PRD-01 FR-9) |
| 오류 | `--danger-weak` 면 + `--danger` 텍스트, "다시 시도" 버튼 |
| 논문 `abstract_only` | 섹션 자리에 `--bg-subtle` 안내 블록 — "전문을 확보하지 못해 초록만 제공합니다" |
| 번역 실패 | `--danger-weak` 배지 + 원문 노출 (PRD-03 FR-9) |

**일러스트를 쓰지 않는다.** 자산 제작 비용이 들고 Toss 톤에서 빈 상태는 대개 텍스트다.

## 9. 접근성 기준

| 항목 | 기준 |
|---|---|
| 텍스트 대비 | **AA 4.5:1 이상.** §2.2의 토큰은 전부 통과값. `--text-disabled`는 정보 전달 금지 |
| 색상 외 구분 | 카테고리 태그는 색을 쓰지 않는다(§2.3). 뉴스/논문 배지는 색 + **텍스트 라벨** 병행 |
| 포커스 | 모든 상호작용 요소에 `--focus-ring`. `outline: none`만 두고 끝내지 말 것 |
| 카드 링크 | 카드 루트가 `<a>`. 내부 배지·태그는 비상호작용 요소 (PRD-04 §4.1) |
| 토글 | 원문/번역 토글은 `<button>` + `aria-pressed` (PRD-04 NFR-8) |
| 결과 건수 | `aria-live="polite"` (PRD-06 NFR-3) |
| 모션 | `prefers-reduced-motion` 존중 (§6) |
| 이미지 | 썸네일 `alt`. placeholder는 장식이므로 `alt=""` + `aria-hidden` |
