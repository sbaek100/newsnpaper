## 2. 운영 빌드 (architecture.md §7.4)

| ID | ID 요구사항 |
|---|---|
| H-1 | 프론트엔드 정적 빌드(`npm run build`)를 Caddy가 서빙한다. 운영에서 Vite 개발 서버를 쓰지 마라 |
| H-2 | 개발/운영 Compose를 `docker-compose.override.yml`로 가른다. 개발은 볼륨 마운트 + Vite, 운영은 정적 |
| H-3 | `/api/*` → `backend:8000`, 그 외 → 정적 파일. **SPA 폴백** — 없는 경로는 `index.html`로 보내 라우터가 처리한다 |
| H-4 | 정적 자산(폰트·SVG)에 장기 캐시 헤더, `index.html`은 `no-cache` |
| H-5 | **CORS를 넣지 마라.** 단일 오리진이다 |

## 3. 🔴 접근성 전수 점검 (design-system.md §9)

선언만 해두고 넘어가기 쉬운 항목이다. **실제로 측정하고 고친다.**

| ID | 요구사항 |
|---|---|
| H-6 | 모든 텍스트 대비비 **AA 4.5:1 이상**. `--text-disabled`(`#8B95A1`, 2.9:1)가 정보 전달에 쓰인 곳이 있으면 전부 고친다 |
| H-7 | 카테고리 태그가 **색으로만 구분되지 않는다** (design-system §2.3 — 글자로 구분) |
| H-8 | 뉴스/논문 배지는 색 + **텍스트 라벨 병행** |
| H-9 | 모든 상호작용 요소에 포커스 링. `outline: none`만 두고 끝낸 곳이 없다 |
| H-10 | 카드 루트가 `<a>`이고 내부 배지·태그가 비상호작용 요소다 (중첩 링크 없음) |
| H-11 | 원문/번역 토글에 `aria-pressed` |
| H-12 | 검색 결과 건수에 `aria-live="polite"` |
| H-13 | `prefers-reduced-motion: reduce`에서 3D 자동회전·마우스추종이 멈춘다 |
| H-14 | 썸네일에 `alt`. placeholder는 `alt=""` + `aria-hidden` |
| H-15 | 키보드만으로 GNB → Hero 검색 → 카드 → 페이지네이션까지 순회된다 |
| H-16 | 폼(로그인·가입)에 `<label>` 연결, 에러가 `aria-describedby`로 연결된다 |

**측정 방법** — axe-core 또는 Lighthouse 접근성 감사를 실제로 돌리고 결과를 보고한다.

## 8. 검증 방법

- [ ] `docker compose -f docker-compose.yml up -d` (override 없이) 로 운영 구성이 뜬다
- [ ] 브라우저에서 `/papers/…`를 **직접 새로고침**해도 404가 아니다 (SPA 폴백)
- [ ] 정적 자산에 캐시 헤더가, `index.html`에 `no-cache`가 붙는다
- [ ] Lighthouse 접근성 점수와 axe-core 위반 목록을 실제로 뽑았다
- [ ] 대비비 위반이 0건이다
- [ ] 키보드만으로 전체 순회가 된다
- [ ] 39개 수용 기준 전부에 통과/실패가 기록돼 있다
- [ ] `pg_dump` 백업이 실제로 파일을 만든다
- [ ] 백업 파일로 빈 DB에 복원이 된다
- [ ] 8일 지난 백업이 삭제된다
- [ ] `README.md`만 보고 처음부터 기동할 수 있다
- [ ] `git status`에 `backups/`·`secrets/`가 없다
