| 항목 | 값 |
|---|---|
| 근거 | roadmap.md 단계 7.3~7.5, PRD-06 전체, PRD-01 §10 |
| 목적 | `/search`, 카테고리 목록 3종, `/feed`, 인증 화면을 완성한다 |
| 선행 조건 | SPEC-007 (공통 컴포넌트), SPEC-006 (API) |

## 1. 🔴 핵심 원칙 — 컴포넌트 하나를 5개 화면이 공유한다

검색 결과·카테고리 목록 3종·내 피드는 전부 **`GET /api/contents`의 파라미터 차이**일 뿐이다
(architecture.md §9, PRD-06 §9.5). 응답 스키마가 같으므로 목록 컴포넌트를 하나만 만든다.

| 화면 | 호출 |
|---|---|
| `/search` | `/api/contents?q=…&type=…&kw=…&sort=…&page=…` |
| `/news/international` | `/api/contents?category=international&sort=recent&page=…` |
| `/news/domestic` | `/api/contents?category=domestic&sort=recent&page=…` |
| `/papers` | `/api/contents?type=paper&sort=recent&page=…` |
| `/feed` | `/api/me/feed?page=…` |

| ID | 요구사항 |
|---|---|
| L-1 | 목록 컴포넌트를 **하나만** 만들고 5개 화면이 재사용한다. 화면마다 복제하지 마라 |
| L-2 | 헤더 문구와 0건 안내만 화면별로 다르다 (PRD-06 FR-17) |

## 3. 검색 결과 `/search` (PRD-06 §4.2)

| ID | 요구사항 |
|---|---|
| S-1 | 질의어와 결과 건수를 헤더에 (FR-9). 건수는 `aria-live="polite"` |
| S-2 | 🔴 **적용된 검색 범위를 헤더에 명시한다** (FR-10) — 한국어 질의는 논문 전문에 닿지 못한다 (PRD-05 §4.2). 이 격차를 숨기지 마라 |
| S-3 | 검색창 placeholder에도 범위를 적는다 (PRD-05 FR-16) |
| S-4 | 질의어 매칭 위치를 카드에서 하이라이트 — 배경 `--highlight`, 텍스트는 `--text` 유지 (FR-11) |
| S-5 | 결과 0건이면 **검색 범위 안내 + 대체 제안** (FR-12). 일러스트 없이 텍스트만 |
| S-6 | 영어 질의가 논문 전문에서만 매칭됐으면 "본문에서 발견" 표시 (FR-13, Could) |
| S-7 | **자동완성을 만들지 마라** — 1차 미지원 (PRD-05 §10.4) |

## 5. 인증 화면 (PRD-01)

| ID | 요구사항 |
|---|---|
| A-1 | `/login`, `/signup` — 이메일 + 비밀번호. **소셜 로그인 버튼을 두지 마라** (PRD-01 FR-11) |
| A-2 | 비밀번호 최소 10자 안내. 클라이언트 검증은 **보조**일 뿐, 서버가 강제한다 |

| A-6 | `/feed` 0건이면 "기본 수집 범위(보안/해킹/사이버/AI) 밖일 수 있습니다" (FR-9) |
| A-7 | 액세스 토큰을 `localStorage`에 두지 마라 (FR-13) |

## 6. 🔴 하드 제약

| 제약 | 내용 |
|---|---|
| 중복 구현 | L-1을 어기지 마라. 화면마다 목록을 복제하면 이 명세는 실패다 |
| 무한 스크롤 | 쓰지 마라 |
| 자동완성 | 만들지 마라 |
| 검색 범위 | S-2를 빼먹지 마라. 사용자가 "본문 검색"을 기대하는데 실제 범위가 좁다 |
| 관리자 화면 | 이 명세 범위 밖이다. 나중에 별도 명세로 |
| 색상 | `var(--…)`만. hex 하드코딩 금지 |

## 7. 검증 방법

- [ ] GNB 검색창과 Hero 검색 바가 **같은 화면·같은 결과**를 낸다
- [ ] 결과 헤더에 질의어·건수·**검색 범위**가 함께 보인다
- [ ] 뉴스만/논문만 필터가 동작하고 URL에 남는다
- [ ] 키워드 칩 다중 선택이 OR로, 카테고리와는 AND로 걸린다
- [ ] 필터 건 URL을 새 탭에 붙여넣으면 같은 화면이 재현된다
- [ ] 페이지 2로 가면 URL에 `page=2`가 남는다
- [ ] 메인 "더보기" → 해당 카테고리 목록
- [ ] 논문 목록이 리스트형, 뉴스 목록이 그리드다
- [ ] 결과 0건에서 **왜 안 나오는지**(검색 범위)를 알 수 있다
- [ ] 목록 페이지에 3D Hero가 **없다**
- [ ] 로딩 시 스켈레톤이 보인다 (스피너 아님)
- [ ] 로그인 없이 검색·목록·논문상세가 전부 된다
- [ ] 구독 키워드 21개째가 거부된다
- [ ] `/feed` 0건 안내 문구가 보인다
- [ ] 목록 컴포넌트가 **하나**다 (`grep`으로 중복 확인)
- [ ] 375px 폭에서 가로 스크롤이 없다
