### 1.2 🔴 3D Hero (PRD-04 FR-3~FR-6, design-system §6)

**Toss 톤의 절제와 인터랙티브 3D는 그냥 두면 충돌한다.** 아래가 상한이다. 넘지 마라.

| 항목 | 기준 |
|---|---|
| 모티프 | **떠 있는 데이터 노드(네트워크 토폴로지) 단일 채택.** 자물쇠·매트릭스 스트림을 쓰지 마라 |
| 색 | 노드·엣지는 무채색 `--border-strong`. 전체 노드의 **15% 이하**만 `--point` |
| 밀도 | 노드 **40개 이하**, 엣지 **80개 이하** |
| 배경 | **투명** — 페이지의 흰 배경이 그대로 비친다. 그라디언트·어두운 배경 금지 |
| 마우스 반응 | 카메라 회전 진폭 **±4°**, `lerp` 계수 **0.05** |
| 자동 회전 | **0.05 rad/s 이하** |
| 카피 뒤 | 카피 영역 뒤 노드는 opacity **0.35** |
| DPR | `Math.min(devicePixelRatio, 1.5)` |
| 모바일 `< 768px` | **3D를 렌더링하지 않는다.** 정적 SVG 폴백 |
| 모션 저감 | `prefers-reduced-motion: reduce`면 자동 회전·마우스 추종 정지 |

| ID | 요구사항 |
|---|---|
| M-6 | React Three Fiber로 구현한다 |
| M-7 | Hero 위에 카피와 검색 바를 오버레이한다. 카피: **"최신 보안 동향과 글로벌 논문을 한눈에"** (FR-6) |
| M-8 | 검색 바에서 실행하면 `/search`로 간다 (PRD-05 FR-14·FR-15) |
| M-9 | GNB 검색창과 **동일한 검색**이 실행된다 |
| M-10 | 3D 리소스는 라우트 이탈 시 해제한다 (메모리 누수 방지) |
| M-11 | 저사양에서 첫 스크롤이 끊기지 않아야 한다 (NFR-4) |

## 4. 검증 방법

- [ ] 스크롤해도 GNB가 고정되고 카테고리 3종·검색창이 보인다
- [ ] Hero의 노드가 마우스를 따라 **부드럽게** 반응한다 (급격하지 않다)
- [ ] Hero 위에 지정된 카피와 검색 바가 겹쳐 보인다
- [ ] 노드 수가 40개 이하, `--point` 색 노드가 15% 이하다
- [ ] 375px 폭에서 **3D가 렌더링되지 않고** 정적 SVG가 보인다
- [ ] OS 모션 저감을 켜면 자동 회전이 멈춘다
- [ ] 폭을 줄이면 열 수가 3 → 2 → 1로 바뀐다
- [ ] 뉴스 영역과 논문 영역이 시각적으로 분리돼 보인다
- [ ] 카드만 보고 뉴스인지 논문인지 구별된다
- [ ] 논문 카드에 이미지가 없고, 뉴스 카드는 깨진 URL에서 placeholder가 뜬다
- [ ] 뉴스 카드 클릭 → 외부 원문 새 탭. 논문 카드 클릭 → `/papers/:id`
- [ ] 논문 상세에 3개 섹션 한국어 번역이 기본으로 보인다
- [ ] 섹션 토글을 누르면 그 섹션만 영어 원문으로 바뀐다
- [ ] 초록만 확보된 논문에서 안내 문구가 보인다
- [ ] "원문 PDF" 버튼이 새 탭으로 열린다
- [ ] 논문 상세 어디에도 전문(fullText)이 없다
- [ ] Lighthouse 성능 점수가 모바일에서 급락하지 않는다
