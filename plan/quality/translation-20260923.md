## 7. 운영 리스크 — EXAONE 구동의 취약성

EXAONE 3.5 공식 배포본은 **현재 transformers에서 구동되지 않는다.**

| 시도 | 결과 |
|---|---|
| transformers 5.17 + 공식 원격 코드 | ❌ `create_causal_mask() got an unexpected keyword 'input_embeds'` |
| transformers 4.57 + 공식 원격 코드 | ❌ `cannot import name 'RopeParameters'` |
| transformers 5.17 + Llamafied 변환본 | ✅ 정상 |

LG의 원격 코드가 transformers 5.x의 **좁은 특정 구간에만** 맞는다.
EXAONE 4.0은 네이티브 지원되나 **1.2B와 32B뿐**이라 이 서버에 맞는 크기가 없다
(1.2B는 학술 번역에 부족, 32B fp16은 64GB로 NUMA를 넘어 4워커 불가).

→ EXAONE 채택 시 **서드파티 변환본 의존**을 받아들여야 한다.
