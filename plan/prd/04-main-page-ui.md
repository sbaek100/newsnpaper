# PRD-04: 메인 페이지 프론트엔드 (3D Hero + 매거진 그리드)

| 항목 | 값 |
|---|---|
| 상태 | **Confirmed** (2026-09-23) |
| 최종 수정 | 2026-09-23 |
| 선행 문서 | PRD-03 (데이터 출처), PRD-01 (역할·로그인 진입점) |
| 후행 문서 | PRD-06 (검색 결과·카테고리 목록 페이지) |

## 1. 목적 / 배경

'컴퓨터 및 정보 보안'을 테마로 뉴스와 논문을 자동 수집·큐레이션하는 웹사이트의
**메인 페이지**를 구현한다. 방문자가 첫 화면에서 서비스 정체성(보안)을 시각적으로
인지하고, 수집된 최신 콘텐츠를 스캔하듯 훑어볼 수 있게 하는 것이 목표다.

디자인 기준: 모던한 매거진 / 뉴스 포털 스타일의 반응형 웹.

메인에 노출되는 콘텐츠는 PRD-03의 **기본 수집 키워드(보안 / 해킹 / 사이버 / AI)** 로
수집된 항목이다.

## 2. 범위

**포함:**
- 상단 고정 네비게이션(Sticky GNB)
- React Three Fiber 기반 3D Hero 섹션 + 오버레이 카피/검색 바
- 반응형 카드 그리드(Masonry/Grid)와 Article Card 컴포넌트
- 썸네일 Fallback 이미지 로직
- **논문 상세 페이지** (§10) — 번역된 3개 섹션 표시 (2026-09-23 추가)

**제외 (Non-goals):**
- 뉴스·논문 수집 파이프라인 및 AI 번역 → PRD-03
- 인증 로직·회원 관리 화면 → PRD-01 (단 GNB의 로그인 진입점은 FR-1에 포함)
- **검색 결과 페이지 / 카테고리 목록 페이지 → PRD-06** (2026-09-23, C-3 해소)
- 검색 질의·색인 구현 → PRD-05
- 뉴스 상세 페이지 — 뉴스는 외부 원문으로 직행한다 (FR-17)
- 회원 개인 피드 화면 → PRD-01 §3

## 3. 사용자 / 역할

PRD-01 §2와 동기화됨 (2026-09-23, C-7 해소).

| 역할 | 설명 | 메인 페이지에서 보이는 것 |
|---|---|---|
| 비로그인 방문자 | 로그인 없이 메인 진입 | 전체 콘텐츠 열람, 검색, 논문 상세, 원문 이동. GNB에 "로그인" 버튼 |
| 일반 회원 | 로그인 상태 | 위 + GNB에 "내 피드" 진입점과 계정 메뉴 |
| 관리자 | 로그인 상태 | 위 + GNB에 "관리" 진입점 |

> 메인 페이지의 **콘텐츠 자체는 역할에 따라 달라지지 않는다.**
> 역할이 바꾸는 것은 GNB의 진입점뿐이다. 개인 피드 화면은 PRD-01 §3의 범위다.

### 4.1 카드 구성 요소 — 단일 정의 (C-4 해소)

기존 FR-9와 FR-18이 카드 구성을 서로 다르게 정의했고, FR-17(카드 전체 클릭)과
FR-9의 "원문 이동 버튼"이 인터랙션을 중복시켰다. 아래 하나로 통합한다.

| 요소 | 뉴스 카드 | 논문 카드 |
|---|---|---|
| 유형 배지 (FR-14) | "뉴스" | "논문" |
| 카테고리 태그 | 국제 / 국내 | — |
| 썸네일 | 있음 (FR-10~12) | **없음** (§4.2) |
| 제목 | `titleDisplay` | `titleDisplay` |
| 요약 | `summaryDisplay` 2~3줄 클램프 | Abstract 번역문 2~3줄 클램프 |
| 메타 | 매체명 · 수집 일자 | 저자(최대 3명 외 n명) · 학회 · 발행일 |
| 상태 배지 | — | 전문 분석 / 초록만 (FR-20) |
| 클릭 영역 | **카드 전체** → 외부 원문 (새 탭) | **카드 전체** → 논문 상세 페이지 |

**별도의 "원문 이동 버튼"을 두지 않는다.** 카드 전체가 하나의 링크다.
논문의 외부 PDF 진입은 상세 페이지 안에만 둔다. 접근성을 위해 카드 루트는
`<a>`로 감싸고 배지·태그는 링크 안의 비상호작용 요소로 둔다.

### 4.2 논문 카드 레이아웃 — 텍스트 중심 (C-5 해소)

arXiv·Semantic Scholar 논문에는 대표 이미지가 없다. 뉴스 카드와 같은 템플릿을 쓰면
FR-11의 placeholder가 **논문 영역 거의 전부에서 발동**해 비슷한 이미지로 도배된다.
FR-13이 논문을 별도 세로 섹션으로 분리했기 때문에 한 화면에 몰려 보인다.

→ **논문 카드는 썸네일 슬롯 자체를 두지 않는다.** placeholder도 쓰지 않는다.

```
┌──────────────────────────────┐
│ [논문]              [전문 분석] │
│                              │
│ 공급망 공격 탐지를 위한        │  ← titleDisplay, 600
│ 그래프 기반 이상 탐지 기법     │
│                              │
│ 본 연구는 소프트웨어 공급망에서 │  ← Abstract 번역, 3줄 클램프
│ 발생하는 이상 징후를 그래프...  │
│                              │
│ Kim 외 4명 · USENIX Sec '26   │  ← 저자·학회, 보조 텍스트 색
└──────────────────────────────┘
```

시각적 변별은 이미지가 아니라 **좌측 컬러 바 또는 상단 얇은 보더**로 준다
(NFR-1의 "큰 색면 금지"를 지킨다). 그리드에서 논문 카드는 뉴스 카드보다
높이가 낮고 균일하므로, 논문 섹션은 균일 CSS Grid가 자연스럽다.

### 5.1 디자인 토큰 — `../design-system.md` 참조

**색상·타이포 스케일·스페이싱·브레이크포인트·라운드·그림자의 확정값은
`plan/design-system.md`에 있다.** 이 문서에 값을 중복해 적지 않는다.

여기서 기억할 것만 요약한다:

- 서체는 **Pretendard 단일 체계** — 세리프를 쓰지 않는다 (C-8 해소, design-system §3.1)
- 폰트는 **로컬 서브셋**으로 배치한다. CDN을 쓰지 않는다 (온프레미스)
- 위계는 **굵기 대비**로 만든다. 색으로 강조하지 않는다
- 포인트 컬러는 배지·1px 보더·좌측 4px 바·텍스트·아이콘에만. 채워진 큰 면은 페이지당 1개
- **카테고리 태그(국제/국내)는 색으로 구분하지 않는다** — 글자로 구분한다 (NFR-5)
- 보조 텍스트는 `#8B95A1`이 아니라 `#6B7684` 이상을 쓴다 (AA 4.5:1)
- 3D Hero의 채도·모션 상한은 design-system §6에 고정돼 있다

## 9. 수용 기준 (Acceptance Criteria)

## 9.1 해소 기록 — 논문 번역문의 표시 위치 (C-1)

**문제였던 것.** PRD-03이 논문 Abstract / Introduction / Conclusion을 번역하는데,
FR-17이 카드 클릭을 외부 원문 이동으로 확정하면서 번역 결과를 보여줄 화면이 없었다.

**결정 (2026-09-23).** 후보 ③ **논문만 사이트 내 상세 페이지**를 채택한다.
뉴스는 기존대로 외부 원문 직행(FR-17), 논문만 상세 페이지로 들어간다(FR-17a).

**이 선택의 이유** — 카드 펼침(①)과 모달(②)은 고유 URL이 생기지 않아
검색 결과(PRD-05 FR-15)와 회원 피드(PRD-01 FR-7)에서 특정 논문으로 링크할 수 없다.
상세 페이지는 그 링크 대상이 되며, PRD-03 FR-16의 "번역문 기본 + 원문 토글"이
그대로 성립한다.

## 10. 논문 상세 페이지 (2026-09-23 신설)

### 10.1 범위

논문 1건의 번역 결과를 보여주는 페이지. **뉴스에는 상세 페이지가 없다.**

경로: `/papers/:id` (확정 경로는 §8 API와 함께 정한다)

### 10.2 기능 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-21 | 논문 제목을 `titleDisplay`로 표시하고, 원문 제목을 함께 보거나 토글할 수 있다 | Must |
| FR-22 | 저자, 학회·저널, 발행일, DOI/arXiv ID를 메타 영역에 표시한다 | Must |
| FR-23 | Abstract / Introduction / Conclusion 3개 섹션의 **번역문을 기본 노출**한다 (PRD-03 FR-16) | Must |
| FR-24 | 섹션별로 원문/번역 토글을 제공한다. 토글 단위는 **섹션 단위**로 하고 페이지 전체 토글도 함께 둔다 | Must |
| FR-25 | `sectionExtractStatus`가 `abstract_only`면 Abstract만 표시하고, 나머지 섹션 자리에 "전문을 확보하지 못해 초록만 제공합니다"를 안내한다 | Must |
| FR-26 | `translationStatus`가 `failed`면 원문을 노출하고 번역 실패 상태를 알린다 (PRD-03 FR-9) | Must |
| FR-27 | 외부 원문 PDF로 이동하는 버튼을 명확히 배치한다 (새 탭) | Must |
| FR-28 | 긴 번역문에 대해 섹션 목차 또는 앵커 이동을 제공한다 | Could |
| FR-29 | `fullTextOriginal`(PRD-03 FR-29)은 **화면에 노출하지 않는다** — 검색 색인 전용 | Must |

### 10.3 비기능

| ID | 항목 | 기준 |
|---|---|---|
| NFR-6 | 가독성 | 번역 본문은 카드보다 넓은 행간(`1.7~1.8`)과 최대 폭 제한(`68~72ch`)을 적용 |
| NFR-7 | 톤 일관성 | 메인과 같은 화이트 기조·Pretendard. 본문만 폭·행간을 달리한다 |
| NFR-8 | 접근성 | 원문/번역 토글은 버튼이며 상태를 `aria-pressed`로 노출 |

### 10.4 수용 기준

- [ ] 논문 카드를 클릭하면 상세 페이지로 이동한다 (외부 PDF로 바로 나가지 않는다)
- [ ] 상세 페이지에 3개 섹션의 한국어 번역문이 기본으로 보인다
- [ ] 토글을 누르면 해당 섹션이 영어 원문으로 바뀐다
- [ ] 초록만 확보된 논문에서 나머지 섹션 자리에 안내 문구가 보인다
- [ ] "원문 PDF" 버튼으로 외부 링크가 새 탭에서 열린다
- [ ] 뉴스 카드를 클릭하면 상세 페이지를 거치지 않고 외부 원문이 열린다

### 11.1 디자인 결정 대기

- [ ] **매거진 스타일 vs Toss 스타일** — 현재 문서는 **전면 산세리프(Pretendard)** 로
      작성돼 있다. 기사 제목에만 세리프를 포인트로 남길지 확인 필요.
      추가로, Toss 톤(절제된 미니멀)과 FR-3~FR-5의 인터랙티브 3D Hero(화려한 연출)가
      약하게 충돌한다 — 3D 씬의 채도·모션 강도를 낮춰 맞춘다는 전제
- [ ] **레퍼런스 이미지 미첨부** — 원문에 `[cite: 1]`로 참조된 이미지가 전달되지 않음.
      여백·카드 비율·컬러 포인트의 구체 기준을 잡으려면 필요
- [ ] 다크 모드 지원 여부
- [ ] 그리드 방식: 뉴스 섹션을 진짜 Masonry로 할지 균일 CSS Grid로 할지
      (논문 섹션은 §4.2에서 균일 Grid로 정리됨)
